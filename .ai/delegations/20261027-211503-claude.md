SUMMARY: Art is now the default (fully planted, no gates, no runner), with an optional Maze toggle and user-placed start/exit gates. The core uses a v2 schema that migrates v1 saves as mazes and backs up an unreadable local save before overwriting it. The camera and resize flash fixes are in. Corn, tractor and animals are redrawn with depth, and music is 86 BPM. I only ran `ak-test`; none of the canvas rendering or UI wiring has been loaded in a browser, so the lead needs to check it there.
FILES: game.js, index.html, styles.css, audio.js, tests/game.test.cjs

The new tests cover art blank and toggle leaving the grid alone, gate validation and undo, tractor not moving on gate placement, a configured run, v2 round trip and partial gates, v1 migration, and replant.
OPEN QUESTIONS: none. Notes for the lead:
- **Core API:**
  - State gets `purpose` (`'art'` or `'maze'`, default art), nullable `start`/`exit`, and a tractor that doesn't depend on the gates.
  - New exports: `isConfigured`, `setPurpose`, `placeGate(s, 'start'|'exit', x, y)` returning `{ok, error}`, and `PURPOSES`.
  - `newBlank` defaults to art; `newBlank({purpose:'maze'})` and `newMaze` keep the pre-placed gates.
  - `regenerate` returns false unless the state is a maze; `replant` keeps the tractor in place.
  - `isSolvable`, `findPath`, `runTo` and `moveRunner` do nothing until the state is a maze with both gates set.
- **Schema v2:**
  - `VERSION` is 2, and files carry `purpose`. `start`/`exit` are omitted when unplaced.
  - Parsing v1 gives a maze and still requires both gates.
  - A v2 gate that is present must be in bounds, cleared and distinct.
  - Without a `tractor` field and without a start gate, the tractor is parked on the first cleared cell.
  - An unreadable save is copied to `cornfield-carver:backup` before the new default art field autosaves.
- **New element IDs:** `btn-maze` (toggle, `aria-pressed`), `btn-place-start`, `btn-place-exit` (`aria-pressed` while armed), `gate-status`, `btn-view` (`aria-pressed`). Maze-only controls carry `.maze-only` and are hidden by `body[data-purpose="art"]`. `mode-run` is disabled until both gates are placed.
- **Gate placement:** the toggle itself is not an undo step. Placement is one-shot: arm a tool, then click or tap a cell, or press Enter on the canvas to place under the tractor. Escape cancels. The canvas `aria-label` updates with mode.
- **`window.__cornfield.view()`** returns `{view, close, t, ox, oy, org, orgY, gridX, gridY, cw, ch, dpr, canvasW, canvasH, layerW, layerH, purpose, mode, place, reduceMotion}`. Cell `(x,y)` is at `gridX + x*t`, `gridY + y*t`. `ORGY=1.25` is a new top margin for tall plants.
- **Flash fixes:**
  - `computeLayout` only resizes the canvas when the rounded width, height or DPR changes, and then redraws synchronously.
  - A ResizeObserver is the only resize source, with `resize` as a fallback.
  - The view defaults to whole-field fit; the only close-up is the explicit `btn-view` toggle, and the camera never glides.
  - Ambient particles and the animated flag are gone, so an idle canvas is static.
  - `prefers-reduced-motion` turns off smoothing, bob, jiggle, hint pulse and particles.
  - Stage heights use `100dvh`.
- **Rendering:** the active actor is always drawn last, on top of the corn. The tractor has side, front and back views. The corn sprite cache now handles tall plants.
