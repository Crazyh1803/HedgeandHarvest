SUMMARY: Added three field sizes: Wide acres (`expansive`, 69×35), Grand estate (`grand`, 105×69) and Harvest country (`vast`, 207×105). All six sizes now show in Settings. The whole-field view now shrinks the tile to fractions of a pixel when it can't fit at 4px, and the full-field layer's backing canvas is capped at about 16M pixels. I haven't run any of this in a browser.
FILES: game.js, index.html, README.md
TESTS: `ak-test` passed, 34 of 34 node tests. Browser checks were skipped because `BROWSER_TESTS=1` wasn't set, so the large sizes were never exercised in a browser. No tests added, as instructed.
OPEN QUESTIONS:
- **Memory cap:** `buildLayer` (`game.js:627`) lowers the layer DPR so the backing canvas stays under 16M pixels; CSS geometry is unchanged. Close-up tile size is also limited to what fits that budget at 1x: 26px on Harvest country, about 46px on Grand estate, and the usual 38px or more on the smaller fields. Close-up on Harvest country is therefore less sharp and less zoomed than on other sizes.
- **Whole-field fit:** `computeLayout` previously forced a 4px minimum tile, which would crop the largest fields. Below 4px it now uses eighths of a pixel, down to a 0.5px floor. On a phone about 360px wide, the tile for 207 columns is under 2px, so individual stalks are barely readable in the whole-field view. Close-up is the way to work in detail there. I did not test carving or tapping precision at that size.
- **Render cost:** a full 207×105 field is 21,735 cells. When corn sways, it draws about that many sprites every frame, which may be slow on low-end phones. I didn't measure it.
- **Settings layout:** the six buttons sit in the existing 3-column grid as two rows, so "Harvest country" may wrap to two lines on a narrow panel. I changed no CSS.
- **JSON limit:** the 207×105 field's JSON is about 22.4k characters (about 22.4k with the pretty-printed export format as well), under `MAX_JSON` of 40000. I left the limit unchanged.
- **PNG export:** the export tile is `max(14, min(40, floor(1040/(w+1.6))))`, which gives 14px on Harvest country, so that image is about 2920 pixels wide. That is within canvas limits.
- **Compatibility:** existing size keys and the save format are unchanged. Odd dimensions are kept, so mazes still work.
