SUMMARY: All the listed pieces are implemented across the four allowed files. `ak-test` Node passes 32/32, including the new personality tests. Browser suites were skipped, and I haven't rendered or run any of the new drawing, music bar or layout code in a browser.

- **Corn:** `core.cornPose` is exported. Each plant gets a seeded period of 8–15 s and a 1.5–2.5 s `sin²` burst with a 5–8° peak, clamped at 0.16 rad, so about 17% are active at once. `drawCorn` draws resting cells as one cached composite. Moving cells draw their cached shadow and plant layers, each rotated about its own root. The composite is built from those same layers, and nothing is rebuilt per frame.
- **Corn below 10 px per tile:** it stays on the composite and skips motion.
- **Runner and animals:** `run.dir` is set in `moveRunner`, so `runTo` is covered, and it isn't serialized. `drawAnimal(g, kind, cx, cy, r, pose, dir)` has new side and back views for all six species. Left is the right-facing profile mirrored. Icons and PNG export pass no `dir`, so they stay front-facing.
- **Music bar:** the new bar sits in the header with `#music-track`, `#now-playing`, `#music-prev` and `#music-next`. The select follows the audible song, or the selected one when muted. A pending target survives rapid skips until the new song's audible onset (6 s cap), and nothing auto-unmutes. The auto-rotate checkbox stays in Settings.
- **Brand, favicon and support links:** the title, header, meta, help and PNG footer say Hedge and Harvest. `favicon.svg` is a green/gold hand-drawn SVG linked with `rel=icon`. Support anchors are static, with `data-placement` main, settings, shared, loaded and completed. `#loaded-support` is revealed only after a successful import or Continue, and hidden again when the import dialog opens.
- **Mobile:** the D-pad is unchanged except for a `contextmenu` preventDefault and `-webkit-touch-callout:none`. The canvas on phone is shorter (46dvh) so the D-pad stays closer to reach, and the bar select is 16px below 620px.

**QA hooks:**
- `__cornfield.cornMotion()` returns `{active, drawn, activeCells, activePlants, visiblePlants, amplitude: 0.16, time}`.
- `posePreview(kind, phase, amount, dir)` takes the new facing (0 right, 1 down/front, 2 left, 3 up/back).
- `animation().dir` reports the runner's facing.
